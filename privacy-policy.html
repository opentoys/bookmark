隐私权政策

Bookmark Clouds · 生效日期：2026 年 9 月 7 日

Bookmark Clouds 尊重并保护您的隐私。本政策说明本扩展会处理哪些数据、处理这些数据的目的及方式。

处理的数据及用途

  • 书签数据：读取书签的标题、网址和文件夹结构，用于在新标签页展示和搜索您的书签。
  • 标签页数据：读取当前窗口中标签页的标题和网址，用于在新标签页展示和搜索已打开的网页。
  • 本地偏好设置：在浏览器本地保存您选择的内容筛选项和瀑布流速度。

数据存储与传输

书签和标签页数据仅在您的设备上由扩展即时处理，不会上传、传输或存储到开发者或任何第三方的服务器。本地偏好设置仅保存在您的浏览器本地存储中。

数据共享与出售

本扩展不会出售、出租或与第三方共享您的数据，也不会将用户数据用于广告、信用评估或与扩展单一用途无关的目的。

有限使用声明

本扩展对从 Chrome API 获取的信息的使用遵守 Chrome 应用商店用户数据政策，包括有限使用要求。相关数据仅用于提供或改进本扩展面向用户的书签与标签页展示功能，不会允许开发者或其他人员读取。

数据保留与删除

本扩展不会在外部服务器保留用户数据。卸载扩展会由浏览器移除扩展所保存的本地偏好设置；您也可以通过浏览器的扩展管理功能清除这些数据。

权限说明

  • bookmarks：用于读取并展示您的书签。
  • tabs：用于读取并展示当前窗口的标签页，以及按您的操作在新标签页中打开链接。

政策变更

如果扩展的数据处理方式发生变化，本政策将同步更新，并在本页面标注新的生效日期。

联系我们

如果您对本隐私权政策有疑问，请通过 GitHub Issues 联系开发者。
