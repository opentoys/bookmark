# Bookmark Clouds

一个 Chrome Manifest V3 新标签页扩展：把书签和当前窗口已打开的网页以漂浮文字云形式展示。

## 安装

1. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」。
3. 选择本项目目录。
4. 新开一个标签页即可使用。

右上角可切换「全部 / 书签 / 标签页」。默认显示书签。顶部输入框可搜索当前选择范围内的标题、链接或书签文件夹；命中文件夹时会递归展示其所有后代书签。所有书签会平铺在可鼠标拖拽旋转的 3D 球面上，最多同时显示 100 个。Three.js 已随扩展本地打包，不依赖网络。每个链接文字的颜色由其 URL 的哈希值前 6 位决定，因此同一个网址始终使用相同颜色。
