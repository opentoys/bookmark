# Bookmark Clouds

一个 Chrome Manifest V3 新标签页扩展：把书签和当前窗口已打开的网页以漂浮文字云形式展示。

## 安装

1. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」。
3. 选择本项目目录。
4. 新开一个标签页即可使用。

右上角可切换「全部 / 书签 / 标签页」。默认显示书签。顶部输入框可搜索当前选择范围内的标题、链接或书签文件夹；命中文件夹时会递归展示其所有后代书签。所有书签会显示为固定视图的 3D 瀑布：首屏最多渲染 100 个，随后从当前全部结果中随机、持续地掉落展示。Three.js 已随扩展本地打包，不依赖网络。每个链接文字的颜色由其 URL 的哈希值前 6 位决定，因此同一个网址始终使用相同颜色。

左上角的「瀑布展示设置」可调整流速；瀑布使用固定视图，文字从上方掉落、从下方流出，鼠标悬浮文字时会暂停流动。

## 隐私权政策

扩展的独立隐私权政策页面为 [`privacy-policy.html`](privacy-policy.html)。启用仓库的 GitHub Pages 后，在 Chrome 应用商店开发者后台的“隐私权政策”字段填写以下直达地址：

`https://opentoys.github.io/bookmark/privacy-policy.html`

不要填写仓库首页、项目主页或网站首页；审核要求该地址直接打开隐私权政策正文，并且无需登录即可公开访问。
